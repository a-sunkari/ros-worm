# ROS-Worm v2.1 validation outputs

This folder contains compact, tracked outputs from the actual-energy-deposition
and neural-volume studies. Large ROOT files remain under the ignored `results/`
tree and are regenerated by the recorded commands/manifests.

- `neural_roi/`: source-member topology audit, sparse resolution-series ROIs,
  geometric convergence, content hashes, and metadata.
- `smoke_focused_edep_1k/`: schema/conservation smoke test only; not a
  scientific estimate.
- `focused_edep_100k/`: first focused falsification run. It is sufficient to
  reject coarse ROI pitches but not to quote final neural dose.
- `focused_edep_1M_seed1/` and `diffuse_edep_1M_seed1/`: historical v2.1
  validation before the missing `G4StepLimiterPhysics` registration was found.
  Retained for audit only; not authoritative for spatial scoring.
- `production/`: authoritative corrected 10M compact results with an enforced
  0.5-micrometre charged-particle limit and neutral post-step localization.
- `sensitivity/`: corrected source, environment, material, and seed effects.
- `chemistry/`: six 10k deposited-energy-weighted Geant4-DNA cases, exposure
  scaling, and Level-1 target-interaction sweeps.
- `figures/`: ten publication-quality PNG/PDF figures and content hashes.
- `release_audit.json`: machine-readable final integrity audit.

Large ROOT and scored-distance caches remain in the ignored result directories;
their hashes and exact macros are recorded in `production/`.

Run `scripts/v2_1/run_authoritative_v2_1.py --stage audit` from the repository
root to verify all tracked release invariants without rerunning transport.
